# Activity-Relay Directory Index

This file is a community-maintained discovery list of public Activity-Relay
Directory servers that relay operators may choose to configure.

Listing is informational. It is not an endorsement, trust list, availability
guarantee, or statement that the Activity-Relay project controls a listed
service. Activity-Relay does not automatically enable, register with, or trust
a Directory because it appears here; each Directory remains explicitly opt-in
in relay configuration.

## Public Directory servers

| Directory origin | Public page | Notes |
| --- | --- | --- |
| `https://directory.argentwolf.org` | <https://directory.argentwolf.org> | Public Activity-Relay Directory operated by Argent Wolf. |

## Inclusion and corrections

Directory operators may request inclusion, removal, or a correction by opening
an issue at <https://github.com/thystra/Activity-Relay/issues> or by contacting
`@alan@friendica.argentwolf.org` on the Fediverse.

Please include the canonical HTTPS Directory origin and enough operator or
project information to verify that the service is intentionally public.
