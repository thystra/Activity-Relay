# Activity-Relay v2.4.0

`v2.4.0` is the stable release of the maintained Activity-Relay fork. It
promotes the production-validated RC6 application code after an operational
soak and adds final stable documentation plus an optional Caddy deployment
example.

## Highlights

- Accepts standards-style `Application` and `Service` server actors, including
  NodeBB actors at implementation-defined paths.
- Signs the exact outbound HTTP `Host` authority sent on the wire and includes
  bounded remote response text in worker errors.
- Publishes the relay public key as X.509 SubjectPublicKeyInfo PEM while
  continuing to accept legacy PKCS#1 actor keys.
- Fans out NodeBB-style public embedded `Announce` activities through one
  relay-signed wrapper that works with follower-style receivers and strict
  traditional subscribers such as Mastodon.
- Publishes privacy-filtered `outbox`, `followers`, and `following`
  `OrderedCollection` endpoints plus `endpoints.sharedInbox`.
- Supports multiple server-local daily summary slots, catch-up reporting,
  archived sent reports, and explicit summary administration commands.
- Keeps operator website settings and content overrides separate from current
  package-managed website sources.
- Includes optional Nginx, Apache, and Caddy reverse-proxy examples. No web
  server is installed, enabled, or required by Activity-Relay.

## Validated interoperability

The release was validated with real signed traffic across these paths:

- Friendica to Activity-Relay to NodeBB;
- NodeBB to Activity-Relay to Friendica;
- NodeBB to Activity-Relay to Mastodon; and
- NodeBB to Activity-Relay to another NodeBB server.

The NodeBB-to-Mastodon test imported the canonical NodeBB status, attachment,
and hashtag without relying on an indirect Friendica follow path. See
[`docs/INTEROPERABILITY.md`](https://github.com/thystra/Activity-Relay/blob/v2.4.0/docs/INTEROPERABILITY.md)
for design and troubleshooting details.

## Upgrade and identity safety

The Ubuntu 24.04 `amd64` package has internal Debian version:

```text
2.4.0-1
```

The release asset is:

```text
activity-relay_2.4.0-1_amd64.deb
```

Package installation and upgrade preserve an existing
`/etc/activity-relay/actor.pem`. The public-key compatibility change alters only
the published PEM serialization; it does not rotate the relay key, actor ID, or
`#main-key` key ID. Back up `actor.pem` and operator configuration before any
upgrade, and verify the actor-key hash remains unchanged afterward.

## Containers

Use the stable version tag:

```text
ghcr.io/thystra/activity-relay:2.4.0
```

The stable release also updates the `2.4`, `2`, and `latest` GHCR tags.

## Artifacts and verification

The release includes the Debian package and `SHA256SUMS`. Verify the checksum
before installation and confirm that package metadata reports version
`2.4.0-1` and architecture `amd64`.
